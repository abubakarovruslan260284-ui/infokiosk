# Карточки товаров на инфокиосках — как это устроено и как запустить

## Схема в одном абзаце

Сотрудник с айфоном и кольцом-сканером UROVO R70 снимает короткий ролик
товара (до 3 секунд) и фото его этикетки. «Быстрая команда» сама называет снимки по штрихкоду и кладёт
их в папку Google Диска «Карточки Товаров». На PC-38 работает служба
`kiosk_cards.exe`: она берёт снимки из Диска, читает штрихкод со снимка
этикетки и сверяет его с именем файла, спрашивает в 1С название и цену
по карте, перекодирует ролик в MP4 (H.264 — его показывают все киоски,
включая Windows 7) и кладёт в `\\wdmycloud\Public\InfoContent` ролик и
его кадр-обложку, `cards.json` (названия и цены) и `manifest.json`. Киоски забирают это
как обычный контент. Цену и название поверх ролика накладывает
киоск по данным, которые подготовил PC-38, поэтому смена цены в 1С — это
несколько байт в `cards.json`, а не перекодирование ролика. Раз в час служба перепроверяет в 1С
цены и остатки всех карточек: при изменении цены карточка обновляется,
при нулевом остатке пропадает с киосков, при появлении товара
возвращается.

Обратной связи с сервером нет: айфону не нужны ни локальная сеть, ни
VPN, ни доступ к WD MyCloud. Ему нужен только Google Диск.

## Порядок запуска

Важно: сначала обновить киоски, потом запускать службу. Старая версия
киоска показала бы фото товаров голыми картинками без названия и цены.

### Шаг 1. Обновить все киоски

1. На каждом киоске удалить старую версию и установить
   `Infokiosk-Setup-x64.exe` из новой сборки.
2. На обычных киосках ничего настраивать не нужно: режим «Витрина +
   проверка цены» включён по умолчанию.
3. На сенсорном киоске для подбора нажать **F3**, в поле «Режим
   киоска» выбрать «Витрина + проверка цены + подбор по цене (сенсорный
   экран)» и нажать «Сохранить». На экране появится кнопка «Подобрать
   товар по цене». Если к этому киоску подключена ещё и внешняя кнопка,
   её можно привязать: «Запомнить кнопку» → нажать её → «Сохранить».

Если карточки в карусели на каком-то киоске не нужны, там в F3 снимите
галочку «Показывать карточки товаров в карусели». Подборка по цене всё
равно будет брать товары из карточек.

**F4** на киоске показывает, сколько карточек он получил и в каком
режиме работает.

### Шаг 2. Служба на PC-38 (192.168.0.100, Windows 10)

1. Установить «Google Диск для компьютера» и войти под **irskom.pr**.
   В Проводнике появится диск `G:` с папкой
   `G:\Мой диск\Карточки Товаров`.
2. Проверить, что PC-38 может записывать в
   `\\wdmycloud\Public\InfoContent`: например, создать там пустой
   текстовый файл и удалить его.
3. Создать папку `C:\KioskCards` и распаковать в неё
   `KioskCards-PC38.zip` из новой сборки: там `kiosk_cards.exe`,
   `ffmpeg.exe` (перекодирует ролики) и эта инструкция.
4. Дважды щёлкнуть `kiosk_cards.exe`. Служба создаст файл
   `kiosk-cards.json` и закроется.
5. Открыть `kiosk-cards.json` Блокнотом и вписать логин и пароль 1С
   (те же, что в настройках киоска). Остальное уже заполнено:

   ```json
   {
     "inbox_dir": "G:\\Мой диск\\Карточки Товаров",
     "output_dir": "\\\\wdmycloud\\Public\\InfoContent",
     "data_dir": "C:\\KioskCards",
     "api_url": "http://192.168.0.14/UT_2017/hs/infokiosk",
     "login": "…",
     "password": "…",
     "poll_seconds": 20,
     "price_refresh_minutes": 60,
     "orphan_minutes": 30,
     "photo_max_side": 1400,
     "require_label_match": true
   }
   ```

   Обратная косая черта в этом файле всегда пишется двойной: `\\`.
6. Проверить связь с 1С: в командной строке в папке `C:\KioskCards`
   выполнить `kiosk_cards --test-1c 4680269373655`. Должны появиться
   название и цена.
7. Включить автозапуск: `kiosk_cards --autostart`. Служба будет
   запускаться свёрнутым окном при каждом входе в Windows.
8. Запустить `kiosk_cards.exe` двойным щелчком (или перезайти в
   Windows). Окно можно свернуть, но не закрывать.

Служба работает в сеансе пользователя, а не как системная служба
Windows: «Google Диск для компьютера» и диск `G:` есть только у
вошедшего пользователя. Поэтому на PC-38 должен быть выполнен вход в
Windows, а сам компьютер не должен уходить в сон.

### Шаг 3. Айфон и кольцо UROVO R70

**Кольцо.** Перевести R70 в режим Bluetooth HID (клавиатура) по
штрихкоду настройки из инструкции к кольцу и подключить к айфону в
«Настройки → Bluetooth». После каждого кода кольцо должно отправлять
Enter: на большинстве настроек это включено по умолчанию.

**Google Диск.** Установить приложение Google Диск и войти под
**irskom.pr** (или под аккаунтом, которому выдан доступ
«Редактор» к папке «Карточки Товаров»). В приложении «Файлы» должна
быть видна папка «Карточки Товаров».

**Быстрая команда «Карточка товара».** В приложении «Команды» создать
новую команду и добавить действия по порядку:

1. **Повторить** 500 раз. Все следующие действия кладутся внутрь
   повтора.
2. **Запросить ввод**: тип «Текст», вопрос «Щёлкните кольцом по
   штрихкоду». Кольцо само впечатает код и нажмёт Enter.
3. **Заменить текст**: в «Предоставленный ввод» заменить
   `[^0-9A-Za-z-]` на пустую строку, с включённым «Регулярное
   выражение». Так убираются случайные пробелы. Переименовать
   результат в переменную **Код**.
4. **Сделать фото**: «Показывать предпросмотр» включено. Это снимок
   товара. Переменная **Товар**.
5. **Сделать фото**: снимок этикетки так, чтобы штрихкод был крупно и
   резко. Переменная **Этикетка**.
6. **Выбрать из меню** с вопросом «Код **Код**. Сохранить?» и пунктами
   «Сохранить», «Переснять», «Закончить».
7. В пункт «Сохранить» положить:
   - **Форматировать дату**: «Текущая дата», формат «Особый»,
     `yyyyMMdd-HHmmss`. Переменная **Время**.
   - **Конвертировать изображение** **Товар** в JPEG.
   - **Задать имя** результату: `Код__Время__photo.jpg`
     (два подчёркивания между частями).
   - **Сохранить файл**: «Спросить, куда сохранить» выключено, путь
     «Google Диск › Карточки Товаров».
   - Те же три действия для **Этикетки**, но имя
     `Код__Время__label.jpg`.
8. Пункт «Переснять» оставить пустым: команда сразу перейдёт к
   следующему кругу, нужно снова щёлкнуть кольцом.
9. В пункт «Закончить» положить **Остановить эту команду**.

Должно получиться два файла на товар, например
`4680269373655__20261121-153012__photo.jpg` и
`4680269373655__20261121-153012__label.jpg`. Через минуту-другую
карточка появится на киосках.

Шаг «Конвертировать изображение» в JPEG обязателен: камера айфона
снимает в HEIC, а этот формат служба не принимает и такие снимки уходят
в ошибки.

### Шаг 4. Доработка 1С (остаток и группа)

Карточки работают и без этого, но тогда служба не знает остаток и не
может сама убирать закончившиеся товары. Задание программисту 1С:

> В ответ HTTP-сервиса `infokiosk`, метод `getgood/{штрихкод}`, добавить
> два поля, не меняя существующие:
>
> - `stock` (число) — остаток товара в магазине в единицах хранения;
>   0, если товара нет;
> - `group` (строка) — наименование родительской группы номенклатуры
>   (`Номенклатура.Родитель`); пустая строка, если группы нет.

Пример для УТ 11. Имена переменных модуля нужно заменить на свои. Склад
и регистр программист подберёт под магазин:

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	ЕСТЬNULL(СУММА(Остатки.ВНаличииОстаток), 0) КАК Остаток
|ИЗ
|	РегистрНакопления.ТоварыНаСкладах.Остатки(,
|		Номенклатура = &Номенклатура
|		И Характеристика = &Характеристика) КАК Остатки";
Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
Запрос.УстановитьПараметр("Характеристика", Характеристика);
Выборка = Запрос.Выполнить().Выбрать();
Остаток = ?(Выборка.Следующий(), Выборка.Остаток, 0);

Ответ.Вставить("stock", Остаток);
Ответ.Вставить("group", ?(ЗначениеЗаполнено(Номенклатура.Родитель),
	Строка(Номенклатура.Родитель), ""));
```

Служба подхватит эти поля сама, без обновления. Проверка:
`kiosk_cards --test-1c <штрихкод>` покажет остаток и группу. По полю
`group` дальше можно будет настроить киоск в отделе на товары своих
групп.

## Где смотреть, если что-то не так

| Что | Где |
|---|---|
| Брак: штрихкод не распознан, не совпал, нет в 1С, нет пары, HEIC, имя не по шаблону | Google Диск, папка `Карточки Товаров\_Ошибки` и файл `список ошибок.csv` в ней (открывается в Excel) |
| Журнал службы | `C:\KioskCards\kiosk-cards.log` |
| Готовые фото карточек | `C:\KioskCards\photos` |
| Исходные снимки после обработки | `C:\KioskCards\archive\<год-месяц>` |
| Что получил киоск | F4 на киоске |

Как исправить брак: переснять товар. Новый снимок с тем же штрихкодом
заменяет старую карточку. Файлы из `_Ошибки` можно удалять.

Как убрать карточку вручную: создать в `C:\KioskCards` файл
`удалить.txt` и вписать в него штрихкоды, по одному в строке. Служба
уберёт эти карточки с киосков и переименует файл в
`удалить — выполнено <дата>.txt`.

## Подбор по цене (один сенсорный киоск)

Посетитель касается кнопки «Подобрать товар по цене» и выбирает сумму:
до 100, 100–300, 300–500, 500–700, 700–1000 или от 1000 ₽. Дальше киоск
у него на глазах «собирает подборку» (секунд семь): мелькают товары,
по шагам идёт подключение к серверу, отбор по цене, сверка с 1С,
монтаж роликов, бежит процент. Это сцена для сторис: её снимает СММщик.
На самом деле всё готово заранее (PC-38 уже подготовил карточки),
поэтому сцена всегда идёт гладко, даже без сети. Затем коллаж из
отобранных товаров (до 12) и их ролики по одному крупно, после чего
киоск возвращается к витрине. Цены у товаров в подборке не показываются,
в заголовке только диапазон. Если во время подбора отсканировать товар,
откроется обычная проверка цены.

Остальные киоски подбор не показывают: они крутят ролики товаров
вперемешку с рекламой, у каждого киоска свой случайный порядок, и на
каждом круге он перемешивается заново.

## Команды службы

```
kiosk_cards                 работать постоянно (обычный режим)
kiosk_cards --test-1c КОД   проверить связь с 1С
kiosk_cards --decode ФАЙЛ   распознать штрихкод на снимке
kiosk_cards --once          один проход и выход
kiosk_cards --publish       переопубликовать общую папку
kiosk_cards --autostart     запуск при входе в Windows
```

Рекламу по-прежнему можно просто копировать в
`\\wdmycloud\Public\InfoContent`: служба заметит новый файл и сама
обновит манифест. Пока служба запущена, `kiosk_publish.exe` больше не
нужен. Файлы `card_*.jpg`, `cards.json` и `manifest.json` в этой папке
ведёт служба, вручную их менять не надо.
